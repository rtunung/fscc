# fscc

fscc is an educational project of mine to implement a working C compiler in F#.
It is important to note that this project merely implements the compiler part.
I don't plan on implementing a preprocessor or compatible C runtime. For those parts, the project is relying on Good Ol' GCC.
## Implemented features
### Features
- [x] Variable Definitions
- [x] Variable Assignments
- [x] Compound Assignments
- [x] Ternary Expressions
- [x] Function Definitions
- [x] if-else Statements
- [x] for and while Loops
- [x] goto Statements
- [x] switch Statements
- [x] Storage Classes

## Supported Types

- [x] int
- [ ] long
- [ ] unsigned Integers
- [ ] float/double
- [ ] char
- [ ] Pointers
- [ ] Structs
